# 智能 OnCall Agent

面向模拟运维数据的本地应用原型，提供知识库问答、多轮工具对话和告警排查三个独立入口。三个入口共用调用与工具层，没有实现三个相互协作的智能体。

## 安装与启动

使用 Python 3.12 或更高版本。以下 PowerShell 命令在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item secret.example.py secret.py
```

打开本地 `secret.py`，在 `API_KEY` 中填写自己的 DeepSeek API 密钥。不要填写到示例文件中；`secret.py` 已被 `.gitignore` 排除。保留空值也能启动首页、健康检查和模拟数据查询；首次请求模型时会明确返回“没有配置 API key”。

也可不创建 `secret.py`，通过 `DEEPSEEK_API_KEY` 环境变量提供凭证。当前实现优先读取本地文件：一旦 `secret.py` 存在，其值会覆盖环境变量，包括空值。更换密钥后重启服务。

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8001
```

浏览器打开 [本地演示页面](http://127.0.0.1:8001)。默认使用 BM25，不需要向量服务。`DAILY_BUDGET` 可配置进程内每日估算阈值，默认 1.0 元；真实模型请求会使用个人 API 额度。内置模型标识和估算单价仅是项目配置，未核验提供方当前服务目录或账单。

## 离线回归检查

安装测试依赖后执行 27 项边界检查：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -B acceptance/check_boundaries.py
```

脚本通过项目相对路径导入代码，导入前注入空的测试凭证、关闭可选向量配置，并拦截外部 HTTP 请求。它不会读取本地 `secret.py`、访问真实模型或写出报告文件；失败时返回非零退出码。主要覆盖工具白名单与参数、证据归属、信息不足、重规划记录、预算、缓存、会话记忆及 SSE 结束标记。`httpx` 仅供 FastAPI TestClient 使用。

需要自行复测真实模型时，可在完成配置后运行 `python eval.py` 和 `python eval_holdout.py`。前者使用 12 道固定题并生成已忽略的 `eval_result.csv`；后者使用 3 道信息不足固定题。关键词命中和低置信度/模糊词命中均是弱指标，不能当作诊断正确率或可靠校准结论。

## 实现范围

- 知识库：6 篇模拟运维手册按小节切为 33 个有效分块。默认 BM25，引用显示资料名与小节；未检索到不代表资料不存在。
- 对话：最多两轮工具查询，SSE 流式输出，保留最近 6 轮消息；未展示的工具轮草稿不会被当作已交付回答。
- 排查：Plan → Execute → 必要时 Replan → 结论。每轮最多 5 个步骤，最多重规划一次；失败的重规划也会记录。
- 边界：工具名称、参数及计划/结论结构校验；仅从成功工具结果的业务字段提取服务证据。信息不足时只建议补充信息与人工核实。
- 调用：缓存区分模型、输出格式和输出额度；每次调用前检查进程内预算，付费调用串行执行。

所有工具只查询 `data/` 内固定模拟数据，不执行回滚、扩容、删除等操作。数据中的人员编号、保留示例 IP、域名、服务和事件用于演示，不代表真实组织或线上状态；手册中的 Linux 路径是故障示例。

## 原型与 AI 辅助边界

本项目是在 AI 辅助下开发、修复与整理的学习/作品演示原型，包含模型生成的问答、证据摘要与原因推测。对这些内容仍需人工复核，不能表述为已投入生产的运维平台，也不将 AI 辅助产出表述为全部独立手写。

模拟数据是固定快照；服务名与信息充足性检查是启发式规则，跨服务根因仍可能误判。没有生产登录鉴权、多用户隔离保证、真实监控平台或变更执行接入。接入真实系统需要另做鉴权、数据适配、失败处理和测试。

预算和缓存只保存在当前服务进程内，重启会清空。内置价格估算不等于平台账单，一次在途调用可能超过阈值，不能提供严格账单封顶。可选向量分支需要额外配置，未包含在本次验收范围中。
