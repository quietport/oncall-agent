# OnCall 公开验收摘要

这是对原验收结论的去敏摘要，不含原始模型请求/回答、截图、机器路径或原文件哈希清单。公开包提供独立离线回归脚本，便于复核程序边界；真实模型输出会随配置与提供方变化。

## 历史验收（2026-11-10）

原本地验收记录报告：27 项独立边界回归全部通过；20 项真实 HTTP 流程/输出检查全部通过，包括知识库、工具对话、SSE、记忆与会话编号隔离、12 个常规场景及 3 个信息不足场景。原 12 题关键词全部命中，这是弱指标，不能解读为诊断准确率 100%。3 个信息不足场景的建议均限制为补充信息和人工核实。浏览器检查观察到对话能够展示异常指标，信息不足页面能够展示受限建议。

历史修复涉及服务证据来源、对话漏答、信息不足仍建议变更、非法工具参数、JSON 结构校验、失败重规划记录、缓存键、每次模型调用前预算检查和手册排查段检索。

上述真实模型与页面结论来自历史本地报告，本次公开整理未再次联网验证。完整真实 API 报告、页面截图、运行 CSV、历史失败备份和机器配置均不随仓库发布，因此公开仓库不能独立核验全部历史真实模型输出。

## 可复现的离线检查

```powershell
python -m pip install -r requirements-dev.txt
python -B acceptance/check_boundaries.py
```

脚本包含 27 项原回归断言，模型响应使用替身。测试环境在导入业务模块前屏蔽本地凭证并禁用向量 API，测试时拒绝任何意外外部 HTTP 请求。脚本仅打印结果，不持久化带路径的失败报告，并在失败时返回非零退出码。

本次公开副本复测（2026-11-11）：27/27 通过；另验证复制空白配置后首页和健康检查可用、模型入口返回明确缺少凭证错误。未调用真实模型。

## 仍未覆盖

没有验证生产鉴权、真实监控接入、线上数据变化、多用户安全隔离或变更执行。向量检索分支未验收。模型摘要与根因可能出错，预算是进程内估算阈值，不是持久化账单控制。
